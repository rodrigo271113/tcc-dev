Knowledge Distribution Treemap

Every rectangle is a file or folder: its area is how much code it holds, its colour is how few people wrote that code. What am I looking at?

The treemap. Folders are boxes drawn around the boxes of what they contain, so nesting on screen is nesting on disk. Area is proportional to size, which means a directory takes exactly as much room as everything inside it. Click a folder to zoom in, click the bar above the chart to zoom back out.

Pony Factor (TF). The smallest number of authors whose combined work covers more than half of a file or folder's code, counted from the biggest contributor down. TF = 1 means one person wrote most of it — if they leave the project, nobody else knows that code. It is the "bus factor" idea applied per node, so lower is riskier, and red marks the code most dependent on a single person.

Directory sizing. Faithful makes area exactly proportional to size, which is honest but leaves small files invisible next to huge ones. Compressed flattens the differences logarithmically so small subdirectories and files grow big enough to see and click — useful for exploring, but areas are no longer literal.
